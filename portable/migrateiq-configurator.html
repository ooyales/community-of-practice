How This Works in Practice
Every highlighted reference in the materials above is driven by the configuration panel. In the production files (strategy brief, one-pager, solution portal, scenario planner), these are implemented as JavaScript template variables that read from the shared migrateiq-config.js file. To generate materials for a different customer, you change ACTIVE_PLATFORM in one file — not hundreds of text references.

For the PDF one-pagers: The generation script accepts a --platform flag (e.g., python gen_onepager.py --platform cognos) that swaps all references at build time.
